# 🔄 Control de Flujo en Java

Repositorio correspondiente a la Actividad 7 de la materia de Computación en Java.

## Características del Programa
Este proyecto se divide en módulos independientes que demuestran el uso de:
- **Ciclo `while`**: Impresión de secuencias numéricas.
- **Ciclo `for`**: Optimización de iteraciones.
- **Estructura `if` + Operador Módulo (`%`)**: Filtro lógico para encontrar números divisibles entre 2 y 3.
- **Ciclo `do-while`**: Validación de datos de entrada a través de la terminal para evitar números negativos.
